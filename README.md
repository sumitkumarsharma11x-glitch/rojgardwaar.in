# ROJGARDWAAR.IN

ROJGARDWAAR.IN is an independent website focused on free, browser-based tools for preparing application documents and preliminary exam-eligibility screening.

## Current public features

- **Eligibility Calculator** — preliminary screening from stored exam information. Results are not official decisions and must be checked against the current recruitment notification.
- **Photo & Signature Resizer** — prepare image dimensions and file sizes for application forms.
- **Document Scanner** — crop and adjust document images in the browser.
- **Image to PDF / PDF to Image** — convert supported images and PDF pages in the browser.

## Important eligibility-data notice

The current 33-record dataset is **screening-only and pending official verification**. No record is marked verified for the current cycle. The calculator must show an official-verification-required outcome until the exact cycle notification, corrigenda, age cut-off/DOB rules, qualifications, category relaxations and post-specific conditions have been reviewed and recorded.

A valid JSON schema or a working automated test does not prove that recruitment rules are legally or factually correct. Do not change `verifiedForCurrentCycle` to `true` without completing the evidence checklist in `docs/eligibility-audit-2026-11-27.md`.

## Privacy and use

Public tools are designed to work in the visitor's browser where stated on each tool page. Visitors should review the downloaded output and compare it with the exact requirements of the official application portal.

ROJGARDWAAR.IN is independent and is not affiliated with any government department or recruitment authority.
